Patient Cases & Clinical Admissions

Transactional patient management using MySQL 8 stored procedures (sp_admit_patient and sp_close_case).

DBMS Transaction Guard: Admissions execute CALL sp_admit_patient(disease, hospital, age, gender, icu). The database verifies capacity, row-locks the hospital, decrements available beds, and rolls back if full. Closing a case invokes sp_close_case(case_id, status), which restores the bed count automatically.
