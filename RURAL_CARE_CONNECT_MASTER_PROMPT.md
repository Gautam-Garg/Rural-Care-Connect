## 1. Problem statement being solved
**Rural Healthcare Access** (SDG 3: Good Health, SDG 9: Innovation & Infrastructure, SDG 10: Reduced Inequalities).
Villagers struggle to find the nearest Primary Health Centre (PHC), do not know what services are free or affordable, miss vaccination drives, and get disease alerts late. The app must be **rural-first, simple, low-bandwidth, and decentralized (district / block / village level), not metro-hospital-centric.**

- Replace big-city sample data with **rural sample data**: PHCs in villages and blocks of at least 3 states (for example Maharashtra, Madhya Pradesh, Bihar). Use realistic names, latitude and longitude.

## 4. NEW features to add

### 4.1 Nearby PHC finder (map)
- Public page with a Leaflet map. The user can: (a) click "Use my location" (browser GPS), (b) click anywhere on the map to drop a pin, or (c) pick State > District > Village.
- Show the nearest PHCs as markers with distance in km, sorted nearest first.
- Implement distance in SQL using the **Haversine formula** (stored procedure `sp_nearest_phc(lat, lng, radius_km)`), so it is a clear DBMS showcase.
- Each marker popup: PHC name, distance, open/closed now, doctor available, services, phone, "Get directions" link.

### 4.2 Affordable care by budget
- New table `Service_Cost` (phc_id, service_name, category, cost_inr, is_free, scheme_name e.g. Ayushman Bharat / Jan Aushadhi / JSY, notes).
- Public page: user enters **how much money they have (Rs.)** and selects a need (fever, delivery, vaccination, injury, medicines, tests).
- Show only PHCs and services they can afford, cheapest and nearest first, with "FREE" badges for government-free services.
- Add a view `v_affordable_services` and a query using JOIN + WHERE cost <= budget.

### 4.3 Vaccination for villages
- Table `Vaccination_Drive` (phc_id, village_id, vaccine, drive_date, time, target_group, doses_available).
- Public page: "Upcoming vaccination drives near me" using the same location picker.
- Admin can add, edit and delete drives. Trigger: when doses_available hits 0, create an alert.

### 4.4 Area-based alerts
- Add `area_level` and `area_id` to `Alerts` so an alert can target a state, district, block or village.
- Public page shows alerts relevant to the user's selected area, newest first, with severity colours.
- Trigger: if a disease's case count in a district crosses a threshold (HAVING query), auto-generate an outbreak alert.

### 4.5 Rural-friendly extras
- **Language switch**: English, Hindi, Marathi (simple JSON translation file; translate main labels and navigation).
- **Low-bandwidth mode**: lightweight pages, minimal images, mobile-first layout, big buttons.
- **ASHA worker role**: new login role that can record village-level cases, vaccination done, and send a request to the PHC. Keep the existing Admin (full control) and Public (view-only) roles.
- **Emergency button**: shows the nearest PHC with phone number and ambulance info, and a "Call 108" link.
- Keep the AI symptom checker idea as a simple rule-based "Which PHC should I visit and how urgent is it?" tool (no external API required).
